# 划词助手 · Windows 版

一个常驻桌面最上层的悬浮图标：

- **鼠标移上去**：图标放大，外圈光环扩散；稍停一下，围绕图标展开扇形的两个选项。
- **两个选项**（点一下切换，会记住，下次还是它）：
  - **中 → 英**：单击图标弹出横向输入框，打中文按回车直接出英文。可在设置里加「同义词」「不同句式/语法的表达」（每行一种，如日常口语、正式书面、被动语态、强调句……）、例句、语法说明。点任意一行复制。
  - **AI 对话**（和 [Canvas Mindflow](https://github.com/Unclesam-13/canvas-mindflow) 一样的追问方式）：
    - **划线追问**：在回答里选中看不懂的一段 → 弹出追问小窗（「追问…」自己写问题，或点预设问题）→ 追问在单独的分支里展开，主回答原样保留；被划的句子变成黄色高亮，点它跳到那条追问。分支里还能继续划线，一层层往下挖，顶上的「‹ 上一层」回到原处。
    - **问答树**：同一窗口里接着问的是 1、2、3…，划线分出来的是 1.1、1.1.1…，点哪跳哪，右键可删除分支。
    - **历史**：每段对话自动保存，可以搜索、打开、删除；「新对话」开始新的一段。保存格式和 Obsidian 插件一致，把保存位置设成 `你的库\Mindflow\对话数据` 就能两边共用。
    - **图片**：Ctrl+V 粘贴截图 / 图片，点 📎 选图片，或把图片文件拖进来，一次最多 4 张。看图需要能看图的模型（Claude，或 DeepSeek 自动改用 deepseek-flash）。
    - 回答支持标题、粗体、列表、代码等格式；可以复制、重新回答；DeepSeek 可联网搜索并附来源。
- **拖动**图标可以移动位置；**右键**图标：设置、新对话、切换模式、开机自启、退出。

支持 DeepSeek、Claude 和其他 OpenAI 兼容接口。设置保存在 `%APPDATA%\FloatSearcher\settings.json`（API Key 只存在本机）。

编译：推送后 GitHub Actions 自动生成单文件 `FloatSearcher-N.exe`，发布在 Releases 的「划词助手 Windows」里。
