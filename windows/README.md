# 划词助手 · Windows 版

一个常驻桌面最上层的悬浮图标：

- **鼠标移上去**：图标放大，外圈光环扩散；稍停一下，围绕图标展开扇形的三个选项。
- **三个选项**（点一下切换，会记住，下次还是它）：
  - **中 → 英**：单击图标弹出横向输入框，打中文按回车直接出英文。可在设置里加「同义词」「不同句式/语法的表达」（每行一种，如日常口语、正式书面、被动语态、强调句……）、例句、语法说明。点任意一行复制。
  - **AI 对话**：正常多轮对话，回车发送，Shift+回车换行；点「新对话」清空。
  - **剪贴板**：复制一段文字后单击图标，内容自动放进对话。设置里二选一：粘贴后自动用预设提示词发送，或等你输入提示词再回车发送；另有一排快捷提示词按钮。
- **拖动**图标可以移动位置；**右键**图标：设置、新对话、切换模式、开机自启、退出。

支持 DeepSeek、Claude 和其他 OpenAI 兼容接口。设置保存在 `%APPDATA%\FloatSearcher\settings.json`（API Key 只存在本机）。

编译：推送后 GitHub Actions 自动生成单文件 `FloatSearcher-N.exe`，发布在 Releases 的「划词助手 Windows」里。
