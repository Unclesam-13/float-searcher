# 划词助手 · Mac 版

常驻屏幕最上层的悬浮图标，和 Windows 版同样的用法，并按 Mac 的习惯做了调整：

- **鼠标移上去**：图标放大，外圈光环扩散；稍停一下，围绕图标展开扇形的选项。
- **扇形选项**（点一下切换，会记住，下次还是它）：
  - **中 → 英**：单击图标弹出横向输入框，打中文按回车直接出英文。可在设置里加同义词、不同句式/语法的表达（每行一种）、例句、语法说明。点任意一行复制。
  - **中文简化**（可在设置里关掉，不在扇形里显示）：有些中文不好直接翻成英文（成语、俗语、网络用语、绕的句子）。输入后回车，先给一个最直白的中文说法，再给更简单的同义词、大白话解释、拆开的主谓宾短句，可选附关键词的英文提示，方便自己翻成英文。点任意一行复制。
  - **AI 对话**（和 [Canvas Mindflow](https://github.com/Unclesam-13/canvas-mindflow)、Windows 版一样的追问方式）：
    - **划线追问**：在回答里选中看不懂的一段 → 弹出追问小窗（「追问…」自己写问题，或点预设问题）→ 追问在单独的分支里展开，主回答原样保留；被划的句子变成黄色高亮，点它跳到那条追问。分支里还能继续划线，顶上的「‹ 上一层」回到原处。
    - **问答树**：同一窗口里接着问的是 1、2、3…，划线分出来的是 1.1、1.1.1…，点哪跳哪，右键可删除分支。
    - **历史**：每段对话自动保存，可以搜索、打开、删除；「新对话」开始新的一段。保存格式和 Obsidian 插件、Windows 版一致，把保存位置设成 `你的库/Mindflow/对话数据` 就能共用。
    - **图片**：⌘V 粘贴截图 / 图片，点 📎 选图片，或把图片拖进来，一次最多 4 张。看图需要能看图的模型（Claude，或 DeepSeek 自动改用 deepseek-flash）。
    - 回答支持标题、粗体、列表、代码等格式；可以复制、重新回答。
- **DeepSeek 联网搜索**：AI 自己判断要不要搜、搜什么，回答用 [1][2] 标注来源，点来源用浏览器打开。
- **不抢焦点**：在输入窗里打字时，你正在用的 App 仍然在前台。
- **所有桌面、全屏 App 上都能看到**图标；拖动图标可以移动位置。
- **菜单栏图标**（右上角）和**右键悬浮图标**：切换模式、打开输入窗、新对话、设置、开机自启、退出。

支持 DeepSeek、Claude 和其他 OpenAI 兼容接口。适用于 macOS 13 及以上，Apple 芯片和 Intel 都能用。

## 安装

1. 从 [Releases](https://github.com/Unclesam-13/float-searcher/releases) 下载 `FloatSearcher-mac-N.dmg`，打开后把「划词助手」拖进「应用程序」。
2. 第一次打开时，macOS 可能提示「无法验证开发者」或「Apple 无法检查其是否包含恶意软件」。这是因为程序没有付费的苹果开发者签名：
   - 点「完成」关掉提示，打开「系统设置 → 隐私与安全性」，在下方找到「划词助手」，点「仍要打开」。
   - 如果提示「已损坏，无法打开」，打开「终端」，运行：`xattr -cr /Applications/划词助手.app`，再打开。
3. 第一次运行会自动弹出设置窗口，选接口、填 API Key，点「测试连接」。

设置保存在 `~/Library/Preferences/com.huaci.floatsearcher.plist`，API Key 只存在本机。

## 编译

推送 `mac/` 下的改动后，GitHub Actions 会在 macOS 上用 `swift build` 编译通用版（arm64 + x86_64），打包成 dmg 发布到 Releases。本地编译：`cd mac && ./package.sh 0`（需要 Xcode 命令行工具）。
