# 划词助手 · 安卓版

**在任何 App 里选中文字、截一块屏幕、或者复制一段话，屏幕最上层就会弹出 AI 浮窗，直接解释、翻译、总结、追问。不用切换 App。**

支持 DeepSeek、Claude，以及任何 OpenAI 兼容接口（通义千问、Kimi、智谱等）。DeepSeek 还可以联网搜索，回答附带来源。

[⬇ 下载最新版 APK](https://github.com/Unclesam-13/float-searcher/releases/download/build-12/HuaciAI-12.apk) · [所有版本](https://github.com/Unclesam-13/float-searcher/releases) · [Windows 版](windows/README.md)

> 适用于 Android 8.0 及以上，安装包约 24 MB。

## 功能一览

### 1. 随处都能叫出来

| 入口 | 怎么用 |
|---|---|
| **划词「问 AI」** | 在浏览器、阅读器、聊天软件里长按选中文字，弹出的系统菜单里点「问 AI」（有的机型要先点「⋮ 更多」）。 |
| **悬浮球** | 屏幕边上的「问」字悬浮球，单击打开浮窗；按住可以拖动，松手自动贴边。 |
| **分享** | 微信等不显示「问 AI」菜单的 App：选中文字后点「分享」，在分享列表里选「问 AI」。 |
| **剪贴板** | 复制一段文字再点悬浮球，浮窗顶部会出现「剪贴板：……」卡片，点「用这段」就能提问。 |
| **复制后自动提示**（可选） | 打开后，在任意 App 点「复制」，悬浮球旁直接弹出「问 AI：……」，点一下就问。 |
| **通知栏** | 运行时通知栏常驻一条通知，点它打开浮窗，也可以从这里进设置或退出。 |

### 2. 问答浮窗

- **一键预设问题**：解释、翻译成中文、翻译成英文、总结、列要点、润色、举例、挑毛病、怎么回复。按钮可以在设置里随意增删改。
- **流式回答、多轮追问**：回答逐字出现，底部输入框可以接着问；可以随时停止，点「复制」或长按回答复制。
- **可选自动执行**：打开「选中文字后自动执行第一个预设」，划词后不用再点按钮。
- **浮窗随你调**：
  - 按住标题栏拖动位置；拖右下角 ◢ 改大小，横屏、竖屏分别记住。
  - 「调节」里可以改透明度（最多 75%），或者一键恢复默认大小。
  - 中间内容整块可以滚动，横屏或窗口很小时也能看全。
  - 点「—」收起成悬浮球，对话会保留；点「✕」关闭并清空。
- **跟随系统深色模式。**

### 3. 截屏提问

- 点浮窗的「截屏」，或者**长按悬浮球**。
- 画面会定格，上面出现一个选框：
  - 拖框内部可以移动选框。
  - 拖四个角或四条边可以调大小。
  - 在框外拖动可以重新画一个框。
  - 「全屏」直接截整个屏幕。
- 点「放进对话框」后，截图会出现在浮窗顶部。这时预设按钮最前面会多一个「提取文字」，其他预设也能直接对截图用，还可以追问。
- 截图提问需要能看图的模型：Claude，或 DeepSeek 的 `deepseek-flash`。选了 `deepseek-v4-pro` 时，带图的提问会自动改用 flash。

### 4. 放大镜识字（离线）

- 点浮窗的「识字」，浮窗会变成一个虚线取景框：
  - 拖框内部移动，拖边或角改大小，大小会记住。
  - 点「识别」，就识别框下面的文字。
  - 快捷用法：长按浮窗标题栏，直接把框拖到文字上，松手就识别。
- 识别出的文字会放进浮窗，接着可以点预设或追问。
- 文字识别在手机上本地完成（Google ML Kit，支持中英文），**不联网、不消耗 API 额度**。

### 5. 中译英速查模式

在设置最上面的「悬浮球模式」里切换到「中译英速查」：

- 点悬浮球，只弹出**一个输入框**，键盘也会自动弹出来。
- 打中文后按回车，英文直接显示在下面。
  - 输入一个词：给出最常用的译法和几个备选。
  - 输入一句话：给出一句完整、自然的译文。
  - 输入英文：会反过来翻成中文。
- 点译文就能复制。翻译完原文会自动全选，接着打字就是查下一个。
- 查过的内容会记住，再查秒出。
- 划词、截屏、通知栏这些入口仍然打开完整浮窗。

### 6. DeepSeek 联网搜索

- 接口选 DeepSeek 时，浮窗里有个「联网」按钮，默认开启。
- 由 AI 自己判断要不要搜、搜什么，最多搜 3 次。搜索用的是 DeepSeek 官方搜索接口，和对话用同一个 Key。
- 回答里用 [1]、[2] 标出信息来源，下面列出来源标题，点标题就用浏览器打开。
- 联网时会自动关闭深度思考。每次搜索按 DeepSeek 的价格计费，大约 0.75 美元 / 1000 次。

### 7. 接口与模型

| 接口 | 默认地址 | 说明 |
|---|---|---|
| DeepSeek | `https://api.deepseek.com` | 一键切换 `deepseek-flash`（快又省）和 `deepseek-v4-pro`（更强）；可开关深度思考，默认关闭以求快 |
| Claude | `https://api.anthropic.com` | Anthropic 官方接口，默认 `claude-sonnet-5-5` |
| 其他兼容接口 | 自己填 | OpenAI 及兼容它的服务，地址填到 `/v1` 这一级 |

用中转服务时，把接口地址换成中转地址就行。设置页的「测试连接」可以马上检查 Key 和模型能不能用。

## 安装与第一次使用

1. 下载 APK，在手机上打开安装。第一次安装时，如果提示「禁止安装未知来源应用」，按提示允许一次。
2. 打开「划词助手」，点「去开启悬浮窗权限」，在列表里打开开关。
3. 选接口类型，填 API Key 和模型名，点「测试连接」，看到「✓ 可以用了」就行。
4. 点「保存并开启悬浮球」。
5. 去任意 App 长按选中一段文字，点「问 AI」试试。

新版本可以直接覆盖安装，之前的设置都会保留。

**小米、华为、OPPO、vivo 等国产系统**：请在系统设置里给「划词助手」打开「自启动」「后台运行」「悬浮窗」，并把电池策略设为「无限制」。否则悬浮球可能被系统清掉。

## 设置说明

### 自定义预设问题

每行一个，格式是 `按钮名 | 要 AI 做什么`。选中的文字会自动附在指令后面；想把它放在指令中间，就写 `{text}`：

```
解释 | 用通俗的话解释这段文字是什么意思，必要时补充背景。
解释成小学生能懂的 | 请把「{text}」解释给一个十岁小孩听。
```

### 打开「复制后自动提示」

1. 在设置页的「剪贴板检测」里，点「去无障碍里打开」。
2. 在列表里找到「划词助手 · 复制后提示」，打开开关。
3. **安卓 13 及以上如果开关是灰色的**：先到「系统设置 → 应用 → 划词助手」，点右上角「⋮ → 允许受限制的设置」，再回去打开。

这个服务只用来发现你点了「复制」，不读取屏幕内容。

## 权限说明

| 权限 | 用来做什么 | 必需 |
|---|---|---|
| 显示在其他应用上层 | 显示悬浮球和浮窗 | ✓ |
| 网络 | 连接你填的 AI 接口 | ✓ |
| 通知、前台服务 | 让悬浮球在后台保持运行（通知栏里那一条） | ✓ |
| 屏幕录制 / 投射 | 截屏和放大镜识字。每次用时系统会请求授权，闲置 90 秒后自动释放 | 用到截屏时 |
| 无障碍服务 | 「复制后自动提示」：只识别「复制」动作 | 可选 |

## 隐私

- **API Key 只保存在你的手机上**，不参与系统备份，也不经过任何中间服务器。所有请求都直接发往你填的接口地址。
- **文字识别在本机完成**，识字时截下的画面不会上传。
- 只有你主动提问时，选中的文字、截图或剪贴板内容才会发给你选的 AI 服务。
- 读取剪贴板时，系统可能会提示「划词助手已从剪贴板粘贴」，这是安卓 10 以后的正常提示。

## 常见问题

**选中文字后菜单里没有「问 AI」？**
有的 App 会把它收在「⋮ 更多」里。微信等 App 不显示第三方菜单，可以选中后点「分享」，在分享列表里选「问 AI」；或者先复制，再点悬浮球。

**截屏时状态栏出现「正在录屏 / 投屏」？**
这是安卓系统的要求，所有截屏类 App 都会显示。闲置 90 秒后会自动停止。

**点了截屏没反应？**
小米、OPPO、华为等系统可能拦截了后台弹窗。这时 App 会提示你，到系统设置里给「划词助手」打开「后台弹出界面」权限就行。

**截图提问报错「所选模型可能不支持图片」？**
换成能看图的模型，比如 `deepseek-flash` 或 Claude。

**悬浮球过一会儿就不见了？**
系统把它清掉了，参考上面「国产系统」那条打开后台权限。

## 自己编译

仓库自带 GitHub Actions：推送到 `main` 分支后，会自动编译 APK 并发布到 Releases，大约 3 到 5 分钟。也可以用 Android Studio 打开仓库根目录，直接运行到手机上。

项目自带固定的签名文件 `app/huaci-debug.jks`，用来保证新版本能覆盖安装。这个签名只适合自己安装，不要用来上架应用商店。

| 文件 | 作用 |
|---|---|
| `FloatService.kt` | 悬浮球、问答浮窗、截屏、识字、剪贴板、中译英速查 |
| `ProcessTextActivity.kt` | 系统划词菜单「问 AI」和分享入口 |
| `AiClient.kt` | 流式请求各家接口，DeepSeek 联网搜索 |
| `ScreenCapture.kt` / `CropOverlay.kt` | 屏幕捕获、截图选框 |
| `ClipWatchService.kt` / `ClipReader.kt` | 发现复制动作、读取剪贴板 |
| `MainActivity.kt` | 设置页 |

`windows/` 目录里是 [Windows 版](windows/README.md)：桌面悬浮图标，悬停展开扇形菜单，支持中译英、AI 对话、剪贴板三种模式。
