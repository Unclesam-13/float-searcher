# 划词助手（安卓）

在任何 App 里选中文字 → 点菜单里的「问 AI」→ 屏幕最上层弹出浮窗，点预设问题一键提问，或自己输入追问。

## 功能

- **系统级悬浮**：悬浮球和回答浮窗盖在所有 App 上面（安卓「显示在其他应用上层」权限）。
- **全局划词入口**：选中文字后，系统菜单里出现「问 AI」（部分机型在「⋮ 更多」里）。
- **分享入口**：微信等不显示第三方菜单的 App，选中后「分享 → 划词助手」。
- **剪贴板**：复制文字后点浮窗右上角「粘贴」。
- **预设问题**：解释、翻译成中文/英文、总结、列要点、润色、举例、挑毛病、怎么回复，可在设置里随意增删改。
- **流式回答 + 多轮追问**，可停止、复制，长按回答也能复制。
- **三种接口**：Claude、DeepSeek（内置 deepseek-flash / deepseek-v4-pro，可开关深度思考），或任何 OpenAI 兼容接口（通义千问、Kimi、智谱等）。
- 跟随系统深色模式；不依赖第三方库，安装包很小。

## 拿到 APK（不用装电脑开发环境）

1. 在 GitHub 新建一个仓库（可设为私有）。
2. 把这个文件夹里的全部内容上传进去（网页上「Add file → Upload files」，注意 `.github` 文件夹也要传）。
3. 仓库会自动开始编译，约 3–5 分钟。打开仓库的 **Releases**，下载 `HuaciAI-数字.apk`。
4. 在手机上打开 APK 安装（需要允许「安装未知来源应用」）。

也可以用 Android Studio 打开这个文件夹，直接运行到手机上。

## 第一次使用

1. 打开「划词助手」，点「去开启悬浮窗权限」，在列表里打开开关。
2. 选接口类型，填 API Key 和模型名，点「测试连接」看到「✓ 可以用了」。
3. 点「保存并开启悬浮球」。
4. 去浏览器或阅读 App 里长按选中文字 → 点「问 AI」。

**国产系统（小米/华为/OPPO/vivo 等）**：请在系统设置里给「划词助手」打开「后台运行 / 自启动 / 悬浮窗」，并把电池策略设为「无限制」，否则悬浮球可能被清掉。

## 预设问题格式

每行一个：`按钮名 | 要 AI 做什么`。选中的文字会自动附在指令后面；想放在指令中间，就写 `{text}`，例如：

```
解释成小学生能懂的 | 请把「{text}」解释给一个十岁小孩听。
```

## 说明

- API Key 只保存在你手机本地（不参与系统备份），请求直接发往你填的接口地址。
- 项目自带一个固定的签名文件 `app/huaci-debug.jks`，保证新版本能覆盖安装；它只用于自己安装，不要用来上架应用商店。
- 代码结构：`FloatService` 负责悬浮球与浮窗，`ProcessTextActivity` 是划词菜单入口，`AiClient` 负责流式请求，`MainActivity` 是设置页。
